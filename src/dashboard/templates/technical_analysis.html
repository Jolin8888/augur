三、关键支撑位与阻力位

类型来源解释
支撑日内低点、近期低点、前低、整数关口、布林下轨跌破后风险上调，跌破后放量说明抛压未结束。
阻力10EMA、20MA/BOLL中轨、50SMA、VWMA、前高多个阻力重合时形成密集压力区，突破需放量确认。
密集区均线 + VWMA + 前高/前低重合用于标记短线交易中最容易失败的位置。

四、市场规则 / 标的市场特性

市场规则影响风险解释

五、SPY / QQQ 大盘背景

对象判断对主标的影响
SPY站上/跌破 MA20、MA50、MA200；多头或空头排列衡量市场广度和系统性风险。
QQQ科技成长风格是否走强高 beta、AI、半导体、成长股信号需看 QQQ 过滤。
共振个股 + SPY + QQQ 同向强共振降低风险；背离则个股信号降权。
